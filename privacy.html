Privacy

This is a placeholder privacy note for a static prototype. It is not a policy for a launched service, and DocChase is not collecting data on a server.

What stays on this device

  • The waitlist form stores name, email, firm name, and firm size in local storage under docchase.waitlist.v1.
  • The app stores the sample firm, checklist changes, pipeline moves, reminder settings, firm name, and tax deadline under docchase.demo.v1.
  • Choosing a file in the upload portal uses the file name only. The prototype does not read or upload the contents.

What this prototype does not do

  • It does not create an account, set a cookie for tracking, or call an API.
  • It does not send email or text messages.
  • The twelve clients in the app are fictional and are here for demonstration.

How to remove it

Use Reset demo data inside the app to restore the sample firm. Clear this site's local storage in the browser to remove the waitlist as well. Closing the tab does not send a copy anywhere, because there is nowhere to send it.
